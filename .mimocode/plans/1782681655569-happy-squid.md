# Plan: Sistema de Administración de Flotas — Diseño Completo F1T02

## [S1] Problema

El sistema actual tiene 7 roles y módulos incompletos. El manual F1T02 define 13+ roles y 4 áreas principales con múltiples submódulos. Se necesita implementar el sistema completo según el organigrama del manual.

## [S3] Estructura de Módulos (5 módulos)

### Módulo 1: Seguridad
- Gestión de Usuarios (CRUD completo con todos los roles)
- Auditoría del Sistema (bitácora de acciones críticas)
- Control de Sesiones (tokens activos, expiración)
- Gestión de Permisos (RBAC granular por módulo/acción)

### Módulo 2: Flota
- Inventario de Flota (ficha técnica patrimonial, Diagrama 3 F1T02)
- Control de Llantas (código EPS, posición,生命周期)
- Asignación de Vehículos (a conductores y sectores)
- Control Documental (licenciamiento, seguro, documentos legales)

### Módulo 3: Operaciones
- Movimientos Diarios (MA 122 01 01, checklist 15 puntos)
- Control Combustible (MA 122 01 02, órdenes de abastecimiento)
- Gestión de Conductores (licencias, categorías, asignación)
- Programación de Rutas (horarios, control de tráfico)

### Módulo 4: Mantenimiento
- Órdenes de Servicio (MA 122 02 01, preventivo/correctivo)
- Control de Llantas (reencauche, rotación,生命周期)
- Tarjeta de Mano de Obra (horas, costos por técnico)
- Almacén de Repuestos (inventario, despacho)
- Control de Lavado (registro, periodicidad)

### Módulo 5: Administrativo
- Control de Costos (fijos prorrateables, variables)
- Indicadores KPI (CKV, IUV, rendimiento)
- Sustitución Vehicular (curva CPA, análisis)
- Configuración del Sistema (metas, parámetros)
- Reportes y Exportación (PDFs, Excel, dashboard)

## [S4] Arquitectura del Sistema

```
┌─────────────────────────────────────────────────────────┐
│                    Frontend (Next.js 16)                 │
├─────────────────────────────────────────────────────────┤
│  5 Módulos × N Submódulos = ~20 páginas                │
│  RBAC por ruta + componente                              │
├─────────────────────────────────────────────────────────┤
│              API Routes (Next.js)                        │
│  ~30 endpoints REST con auth JWT                        │
├─────────────────────────────────────────────────────────┤
│              Prisma ORM 7.8 + PostgreSQL                 │
│  Multi-schema: seguridad, flota, operacion,              │
│  mantenimiento, administrativo                           │
└─────────────────────────────────────────────────────────┘
```

## [S5] Flujo de Autenticación

1. Login → JWT token (8h expiración)
2. Token en cookie + localStorage
3. Middleware RBAC: Lee cookie, decodifica JWT, verifica rol por ruta
4. API routes: `withAuth()` verifica Bearer token o cookie
5. Sidebar: Filtra módulos según rol del usuario
